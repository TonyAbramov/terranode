# ハードウェア構成とコンポーネント

## ハードウェア一覧
* **マイクロコントローラ:** Seeed Studio XIAO ESP32-S3
* **トランシーバーモジュール:** EBYTE E22-900T22D (2基、Semtech SX1262 LoRaコア採用)
* **アンテナ:** 868 MHz LoRa用アンテナ (2本)
* **プロトタイピング:** ブレッドボード (2枚) ＆ ジャンパーワイヤ

## 開発・テスト環境
* **ファームウェアIDE:** Visual Studio Code (PlatformIO)
* **シリアルデバッグ・モニタリング:** PuTTY

## 電源・展開に関する注記
* *現在のフェーズ:* ベンチテストおよび見通し内 (Line-of-sight) RF検証。
* *次のフェーズ:* 森林樹冠下でのフィールド展開に向けた、自律型ソーラー電源および気象・土壌センサーの統合。
